## Docker Desktop 无法启动诊断（晚间，20:00 左右）

用户报 "ds 不会运行 / es 不会运行"。
根因：**Docker Desktop 守护进程没有启动**，且存在残留进程导致启动被弹窗拦截。
- `docker ps` 报错 `failed to connect to the docker API at npipe:////./pipe/dockerDesktopLinuxEngine... The system cannot find the file specified.`
- Docker Desktop 启动时弹窗 "Lingering processes detected"（残留进程：Docker Desktop.exe ×3、com.docker.build.exe）。
- 当前沙箱环境无法直接点击 GUI 弹窗或安全启动 Docker Desktop，自动 Start-Process 后未成功拉起引擎。

处理：已清理残留 Docker 进程。下一步需用户在弹窗点 **Stop processes**（或直接打开 Docker Desktop），等托盘图标/任务管理器出现 `com.docker.backend.exe` 且 `docker ps` 不再报错。

Docker 正常后需依次启动：
1. `docker compose -f docker/docker-compose.yaml up -d`（mysql / elasticsearch / kibana / qdrant / embedding）
2. `.venv\Scripts\python.exe -m uvicorn main:app --port 8000`（后端 data service）

"ds" 应指后端 FastAPI 服务（data service / 问数服务），"es" 指 elasticsearch 容器。
